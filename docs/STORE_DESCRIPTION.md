# Mac App Store Listing: Caffeinate-d

## App Name
Caffeinate-d

## Subtitle
Stay awake with one click

## Description
Keep your computer awake with a single click. Caffeinate-d is a lightweight menu bar utility for presentations, long downloads, and other tasks that need the display to stay on.

Using system power management, Caffeinate-d can prevent display and idle system sleep while it is active. Turn it on indefinitely or choose a 1, 2, 5, or 10 minute session. Turn it off at any time from the menu bar.

### Key Features:
- **Instant Toggle**: Switch between 'Awake' and 'Normal' modes directly from your menu bar.
- **Status Indicator**: Shows the current awake state in the menu bar.
- **Minimalist Footprint**: Runs as a background-only app (LSUIElement); no Dock clutter or unnecessary windows.
- **Launch at Login**: Optionally start Caffeinate-d when you sign in.

### When to use Caffeinate-d:
- During long file transfers or backups.
- While presenting to an audience.
- When monitoring long-running scripts or compiles.
- To keep the display awake for a short task.

Caffeinate-d does not prevent sleep when a laptop lid is closed. Timed sessions are optional; the app does not collect or transmit personal data.
