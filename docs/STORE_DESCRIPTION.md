# Mac App Store Listing: Caffeinate-d

## App Name
Caffeinate-d

## Subtitle
Keep Mac awake with one click

## Description
Keep your Mac awake with a single click. Caffeinate-d is a lightweight menu bar utility for presentations, long downloads, and other tasks that need your Mac to stay awake.

Built with native macOS power management, Caffeinate-d can prevent display and idle system sleep while it is active. Turn it on indefinitely or choose a 1, 2, 5, or 10 minute session. Turn it off at any time from the menu bar.

### Key Features:
- **Instant Toggle**: Switch between 'Awake' and 'Normal' modes directly from your menu bar.
- **Native Status Indicator**: Uses macOS system symbols in the menu bar.
- **Minimalist Footprint**: Runs as a background-only app (LSUIElement); no Dock clutter or unnecessary windows.
- **Launch at Login**: Optionally start Caffeinate-d when you sign in.
- **One-Click Support**: Integrated links for documentation and developer support.

### When to use Caffeinate-d:
- During long file transfers or backups.
- While presenting to an audience.
- When monitoring long-running scripts or compiles.
- To prevent your Mac from locking while you're away for just a moment.

Caffeinate-d does not prevent sleep when a MacBook lid is closed. Timed sessions are optional; the app does not collect or transmit personal data.
