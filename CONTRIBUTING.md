# Contributing to Caffeinated

First off, thank you for considering contributing to Caffeinated! It's people like you that make the open-source community such a great place.

## Code of Conduct

Please be respectful and professional in all interactions.

## How Can I Contribute?

### Reporting Bugs
- Use the **Bug Report** template.
- Provide as much detail as possible (macOS version, app version, steps to reproduce).

### Suggesting Enhancements
- Use the **Feature Request** template.
- Explain why the feature would be useful.

### Pull Requests
- Fill out the **Pull Request** template.
- Ensure your code follows the existing style.
- Verify that the app builds successfully using `xcodebuild`.

## Development Setup

1. Clone the repo.
2. Open `caffeinated/caffeinated.xcodeproj` in Xcode.
3. Build and run.
